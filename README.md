# 🚗 小白汽车调音 — 手机端汽车音响RTA调音工具

## 这是什么？

一个运行在手机上的汽车音响调音APP。通过播放粉红噪音、手机麦克风收音、实时频谱分析(RTA)，自动诊断车内声学缺陷并给出DSP EQ调整建议。

## 两种使用方式

### 方式一：手机上直接打开HTML (最简单)

1. 手机连接车载蓝牙
2. 用手机浏览器打开 `index.html`（需通过HTTP服务器，因为麦克风权限要求）
3. **启动本地服务器**：电脑安装Python后运行 `python serve.py`，手机连同一WiFi，浏览器访问 `http://电脑IP:8080`
4. 点击 ▶ 按钮开始测试
5. 30秒后自动分析并显示EQ建议

> ⚠ **重要**：Chrome/Edge 出于安全限制，禁止从 `file://` 打开的文件使用麦克风。必须通过 `http://` 访问。

### 方式二：安装APK (推荐)

直接将APK安装到手机，获取完整麦克风权限：

1. 编译APK（见下方）
2. 传到手机
3. 允许"安装未知来源应用"
4. 打开APP → 连接蓝牙 → 点击播放 → 自动分析

## APK 编译方法

### 本地编译 (需要安装 Android Studio)
```bash
# 打开 Android Studio → Open → 选择 android/ 文件夹
# Build → Build APK
# 或运行:
cd android
build-apk.bat
```

### GitHub Actions 自动编译
1. Fork/Push 到 GitHub
2. 进入 Actions 标签页
3. 手动触发 Workflow → Build APK
4. 下载编译好的APK

## APP功能

- 🔬 **实时频谱分析**：31段ISO标准频段 (20Hz-20kHz)
- 🎤 **双模式收音**：外录(麦克风) / 内录(内部信号)
- 📊 **频响曲线显示**：实时绘制+目标曲线对比
- 🎯 **智能诊断**：自动识别波峰/波谷，分析声学原因
- 🎛 **EQ建议**：削峰为主填谷为辅，专业Q值计算
- 📋 **哈曼目标曲线**：符合车载音响标准
- 💾 **会话保存**：支持保存/导出/对比多次测试结果

## 测试位置

支持三种收音位置测试：
- 中心位（前排后排之间，左右居中）
- 主驾位（驾驶员耳朵高度）
- 后排中心位

建议三个位置都测一遍，综合最佳效果。

## 注意事项

1. **手机摘掉手机壳**以获得更好的收音效果
2. 测试时**关闭车窗**，减少外部噪音
3. 音响初始状态：EQ全部归零(Flat)，关闭环绕声
4. 音量设为正常听音水平（约75-85dB）

